## 更新内容

- **设置菜单重整**：从 10 项平铺改为 6 项分组——图片显示 / 订阅源 / 缓存清理 / 检查更新 / 收藏 / 诊断
- **新增「图片分辨率」**：可选「自动（按屏幕宽度）」或 480 / 600 / 800 / 1000 / 1200 / 1600 px。不同设备屏宽不同，这里可各取所需；改档位后当天缓存自动清空，下次抓取生效
- **源连通性自检**：改用与「检查更新」同款的进度条，探测移到子进程——**界面不再假死，点击即取消**（连域名解析卡住也能中断）
- **诊断更可靠**：网络诊断修好 TLS 握手判定与取消；新增「重新允许 gzip 压缩」，万一压缩功能被误判停用可一键恢复
- **一批健壮性修复**（共 14 项）：
  - 更新：下载异常时不再毫无提示；安装阶段禁止取消（避免插件目录被删空）；点击进度条不再误触下层菜单
  - 网络：失败重取不再丢失证书校验；压缩解压的熔断只对真正的平台故障生效（个别数据损坏不会让设备永久降级）
  - 阅读：改图片/订阅设置不再删除**正在阅读**的那一期；菜单勾选项点击即时刷新
  - 图片：分辨率提高时整期图片额度同步放大（不会"越清晰图越少"）；超高图有专门的小尺寸兜底；同一张图在多篇文章里只存一份
  - 提示：「N 张图未取到」按真实原因显示（过大 / 额度已满 / 图床不可用），不再重复累加
- **改个名**：菜单「往期缓存」→「缓存期刊」

## 升级方式

设置 → 检查更新 →「更新到 v0.2.0」。

若当前版本已无法联网抓取（更新检查也打不开），把下方 ZIP 解压后覆盖 `plugins/zhifou.koplugin/` 即可。
