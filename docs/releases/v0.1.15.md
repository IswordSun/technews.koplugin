## 升级方式

KOReader 里打开 **知否 → 设置 → 检查更新**，会显示「更新到 v0.1.15」，点击即可自动下载安装（直连不通时自动走镜像），装完重启 KOReader 生效。也可以下载下方 ZIP 手动放进 `koreader/plugins/`。

装过 v0.1.14 的直接升即可；v0.1.13 及更早也能升（更新器兼容新旧两种目录名）。

## 重点：抓取不再卡住

### 「读首诗再睡觉」每次抓取卡一两分钟 — 已修

查出来的原因是它家的 feed 有 **2.01MB**（WordPress 把每首诗全文，含两三万字的赏析，都塞进了 feed），而插件此前从不告诉服务器"我支持压缩"，于是每次都老实下满 2MB。设备端单次请求的总超时是 30 秒，弱网（≈60KB/s）下需要 **32 秒** → 超时失败 → 自动重试 4 次 → **卡约两分钟**。

这一版让所有请求都声明支持压缩，服务端压完只有 **204KB**：

| | 下载量 | 用时 | 结果 |
| --- | --- | --- | --- |
| 改前 | 1.92MB | 32.0 秒 | ✗ 超时 → 重试 ≈ 卡两分钟 |
| 改后 | 204KB | **4.3 秒** | ✓ 通过 |

所有源都受益（IT之家、虎嗅等 feed 同样被压缩传输），实测一期抓取从"最慢的源拖后腿"变成整体约 1 分钟。

### 一个坏源不再拖垮整期

- 新增**整期抓取时间预算**（300 秒）：超时自动跳过剩余源，并在完成提示里写明「抓取超时已跳过 N 个源」
- 新增 408/425/429 重试，遇到 **429 限流会听服务端的 `Retry-After`**（最长等 10 秒）
- 重试间隔改为指数退避（0.5/1/2 秒）加随机抖动，多个源同时失败也不会一起重试
- 给所有响应加了**字节上限**（图片 3MB、其它 8MB），异常大响应会被就地中断，不再可能把内存撑爆

## 不再产出「只有标题」的空文章

抽取器现在会自检：如果定位到的正文容器里明明有大段文字，但抽出的正文不到 5%，就判定为"站点改版导致抽取失效"，**自动回退到 RSS 摘要**并记日志——以前这种情况会安静地产出一篇只有标题的空白文章。

实测 6 个需要抓正文的源（少数派、量子位、InfoQ、快科技、9to5Mac 等）正常保留率在 15%~85%，阈值留足了余量，不会误伤。

其它同类修复：

- RSS 里的非法时间（如 `2026-13-45`）不再被静默"进位"成错误日期，按无时间戳处理
- 知乎日报某一篇正文抓取失败时跳过该篇继续，不再整天没内容
- Readhub 早报改为按结构校验条目区段，站点改版后文末的推荐位不会再被当成正文吸进来

## 在线更新的安全加固

更新器下载的是**要执行的代码**，这一版给它补上了两道锁：

- **TLS 证书校验**：更新链路的 API 请求与安装包下载都启用证书校验（用 KOReader 自带的 CA 库）
- **安装包 SHA256 校验**：从 GitHub 拿到官方摘要后逐字节比对；对不上就删掉、自动换下一个镜像——国内镜像回退是日常路径，这道校验能挡住被投毒的镜像

实测：正常下载通过校验（与 GitHub 报告的大小、摘要一致），把包里改一个字节会被正确拒绝。

## 更快、更好排查

- **新菜单：设置 → 源连通性自检**。一次列出每个已订阅源是否可达、各花多少秒、最慢的是哪个，不用再"改设置→抓一次→看谁失败"来回试（自定义源会标注跳过）

  实测：13 个启用源中可达 11 个，最慢为「读首诗再睡觉」9.1 秒（与其 feed 本身响应慢相符）
- 收藏索引与条目侧车文件加了**解析缓存**：打开首页与阅读器内「⋯」菜单时不再重复解析同一份文件，低配设备上更跟手

## 本版改动一览

| 类别 | 内容 |
| --- | --- |
| 网络 | gzip 压缩（省一个数量级流量）、429/Retry-After、指数退避+抖动、响应体字节上限、整期 300 秒预算、腾讯 COS 图片缩放规则 |
| 内容 | 抽取器空壳守卫、RSS 时间字段校验、CDATA 全局剥离、知乎日报单篇容错、Readhub 区段结构校验 |
| 安全 | 更新链 TLS 证书校验、安装包 SHA256 校验 |
| 体验 | 源连通性自检、收藏索引/侧车解析缓存 |

测试：**16 个 spec / 660 项断言**全绿，`luacheck` 零告警；发布前自动跑测试与静态检查。

## 已知边界

- 知乎部分图片是「`.jpg` 的 URL 里装 PNG 字节」，其图床忽略转格式参数，只能按原样收录（判型与显示正常，仅体积压不下去）
- 源连通性自检只探测订阅源入口是否可达，不代表正文抽取一定正常
- 更新包下载仍不支持断点续传（单个包约 110KB，影响有限）
