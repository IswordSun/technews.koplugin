## 更新内容

- **新增自定义源**：设置 → 订阅源设置 →「＋ 添加自定义源…」，粘贴任意 RSS/Atom 地址（可一次贴多行）即用。
  名称自动取 feed 标题，可重命名、调条数、切换「用 feed 摘要 / 逐篇抓全文」、测试可达性、删除
- **修一批正文丢失的问题**：代码块、表格、引用块此前会**整块消失**——技术类文章（博客园/掘金/美团/InfoQ）受影响最大，
  实测某篇博客园文章正文 8.4KB 全在表格里，修复前只抓到 2143 字、修复后 12061 字
- **文章改为按时间从早到晚排列**（此前是最新在前）
- **新增阅读排版**：设置 → 阅读排版，可选「紧凑 / 标准 / 宽松」（段间距与行距）；
  正文左右留白收窄，代码块/表格/引用块有了专门的样式，链接改为可辨认的蓝色下划线
- **修 RDF 源多出一条幽灵条目**：某些源（如 Slashdot）会混进一条标题是站点名的假条目
- 菜单「往期缓存」改名为「缓存期刊」；抓取进度不再显示耗时（更清爽）

## 升级方式

设置 → 检查更新 →「更新到 v0.2.1」。
