## 升级方式

KOReader 里打开 **知否 → 设置 → 检查更新**，会显示「更新到 v0.1.14」，点击即可自动下载安装（国内直连 GitHub 不通时自动走镜像），装完重启 KOReader 生效。也可以下载下方 ZIP 手动放进 `koreader/plugins/`。

## 本版重点：一期体积降到原来的 1/5 左右

来源站的图片原本是「原图直下」，一期动辄 22–34MB。这一版把图片链路整个重做：

- **按图床套 CDN 缩放**（宽 800，超高图自动降到 480）
- **PNG/GIF 让 CDN 直接输出 JPEG**（这部分是体积大头）
- **默认转灰度**（墨水屏上彩色没有意义；`设置 → 图片转灰度（省体积）` 可关）

实测（同一批 200 张真实图片）：**81.1MB → 13.3MB，省 84%**。几个典型单张：

| 图片 | 处理前 | 处理后 |
| --- | --- | --- |
| 知乎动图（GIF） | 8.6MB | 19.7KB |
| 知乎动图（GIF） | 4.6MB | 59KB |
| 「一个」配图 | 792KB | 37KB |
| 虎嗅截图（PNG） | 1.14MB | 141KB |
| 少数派截图（PNG） | 100KB | 22KB |

模拟器实抓一期验证：**10.5MB / 281 页 / 151 张图**（旧版同规格一期为 22.5–34MB）。

另外加了体积闸门，避免个别巨图把整期撑爆：单张 ≤1.5MB、整期 ≤12MB、张数 ≤150；超限会先降档重试，仍超则略过并在完成提示里写明「N 张图过大已略过」。

## 阅读正确性（EPUB 合规）

- 正文图片**逐张登记进 OPF manifest**（旧版一张都没登记，用 epubcheck 校验是不通过的）
- 补上 EPUB 3 必需的 `dcterms:modified`；`identifier` 带上期号（旧版同一天的各期 ID 完全相同）
- 修正 NCX 目录的 `playOrder` 顺序（旧版父节点编号晚于子节点，文档流非单调）
- 剥离正文里的 XML 非法控制字符（源站偶发带入，会让整篇文章成为非法 XML）
- 封面不再重复存一份：封面取自正文首图时直接复用该图，每期省下一张最大的图

## 数据安全

- **缓存命中要求文件完整**：写盘中断留下的截断 EPUB 会被识别并重新抓取（旧版会当成有效缓存，打开报 invalid document 且永不重抓）
- **写盘失败会被发现**：`flush`/`close` 出错时删掉半成品并报错，不会把截断文件改名成正式期文件
- **收藏索引损坏不再静默清空**：先把原索引备份为 `favorites.lua.broken-<时间戳>`，并在首页提示；备份失败时拒绝写入，避免覆盖唯一副本
- **启动清理不再误删正在阅读的那一期**（旧版可能连同阅读进度一起删掉）
- 在线更新解压时**拒绝符号链接条目**，避免恶意包写穿插件目录

## 交互体验

- 每个源在**发出第一个网络请求之前**就显示「正在连接 X…（点击可取消）」——旧版在弱网下会有长达一两分钟毫无反应的"假死"
- 某个源抓取失败时，完成提示里会写明「**本期未取到：源A、源B**」，不再默默少内容
- 修复「往期缓存」列表里同一天合并期排序错乱的问题

## 兼容与工程

- 发行包顶层目录本版起为 `zhifou.koplugin/`（v0.1.13 及更早的设备更新器两种目录名都接受，可正常在线升级）
- 测试增至 **13 个 spec / 545 项断言**，`luacheck` 零告警；发布脚本加了发布前门禁（测试 + 静态检查不过不发版）

## 已知边界

知乎部分图片是「`.jpg` 的 URL 里装 PNG 字节」，其 CDN 忽略转格式参数，只能按原样收录（本期约 3.5MB 属于这类）。判型与显示都正常，仅体积压不下去。
