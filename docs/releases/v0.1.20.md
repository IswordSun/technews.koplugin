## 更新内容

- **修「部分设备所有源都抓不到」**：v0.1.15 起的 gzip 压缩在 zlib 不完整的设备（如 Boox Nova3）上会抛错并中断整个请求 → 现在会先探测实际可用的解压能力，不可用就走明文；异常也不再外泄。
- **图片下载不再卡很久**：同一图床连续失败 3 次即跳过剩余图片，只有"图太大"才降清晰度重试，整期有时间上限。
- **抓取过程看得见**：重试时显示「第 N 次重试（点击可取消）」，图片进度带已用时间。
- **新增两个诊断入口**：设置 →「网络诊断（分阶段）」「最近错误（诊断）」——以后设备上抓不到东西，屏幕上就能看到卡在哪一步。

## 升级方式

设置 → 检查更新 →「更新到 v0.1.20」。

若当前版本抓不到源（更新检查也打不开），把下方 ZIP 解压后覆盖 `plugins/zhifou.koplugin/` 即可。
