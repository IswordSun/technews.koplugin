# technews.koplugin

个人自用的 KOReader 插件：把多个科技资讯源（RSS/网页）抓取为**每日一期 EPUB**，用 KOReader 原生阅读器阅读。

## 功能

- **多源订阅**：内置 6 个源（IT之家、雷锋网、爱范儿、极客公园、Solidot、少数派）；首次打开多选订阅，可在「订阅源设置」随时调整
- **每日一期**：严格取本地当日 0 点后的条目（不回补），按时间倒序；支持合并期与单源阅读
- **全屏首页**：主菜单单入口 → 全屏首页（打开今日资讯 / 重新抓取今日 / 我的收藏 / 分源阅读 / 设置 / 关于）
- **图文完整**：收录文章全部图片，经 CDN 缩放（宽 800）控制体积；跨源标题自动去重；带小标题的长文（如早报）在目录里提供二级跳转
- **文章收藏**：阅读时一键收藏/取消，收藏为单篇快照 EPUB（打开即正文，独立于缓存，永久保存）
- **阅读体验**：右上角「⋯」快捷菜单（目录 / 收藏 / 删除并返回 / 关闭并返回）；读到最后一页会问是否返回
- **省心**：缓存保留 7 天自动清理；当日可一键重抓；抓取进度可读、可取消

## 安装

1. 把 `technews.koplugin/` 整个目录拷到 KOReader 的 `plugins/` 目录（如 `koreader/plugins/`）
2. 重启 KOReader
3. 主菜单 → 工具 → **科技资讯订阅**

> 需要联网；首次打开会引导选择订阅源。

## 使用

- **打开今日资讯**：抓取全部已启用源 → 生成合并期 → 自动打开
- **重新抓取今日**：清掉当日缓存后立即重抓（带进度显示）
- **我的收藏**：收藏列表（标题 · 收藏日期），点击打开单篇快照；「设置 → 管理收藏」可删除
- **分源阅读**：按已启用源逐源出刊
- **设置**：订阅源设置（勾选启停）、包含图片（默认开）、清理全部缓存
- **阅读器内**：右上角「⋯」打开快捷菜单（目录 / 收藏文章 / 删除并返回 / 关闭并返回）
- 快捷菜单也可绑手势：Dispatcher 动作 `technews_quickmenu`

## 开发

```bash
bash scripts/run_specs.sh                # Lua 规格测试（9 个 spec / 298 项断言）
luacheck technews.koplugin spec          # 静态检查
bash scripts/make_snapshot.sh "<描述>"   # 里程碑快照（可安装 ZIP + 完整 git 历史 bundle）
```

实现零第三方依赖，全部为纯 Lua：手写最小 EPUB 构建（流式写盘）、最小 ZIP 读取器（收藏就地取图）、RSS 解析与网页正文抽取。

里程碑节奏：提交 → 升 `main.lua` 版本号 → `git tag` → 打快照（`snapshots/`，不进版本库）。
