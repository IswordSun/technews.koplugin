# zhifou.koplugin

个人自用的 KOReader 插件「知否」（包名 zhifou.koplugin）：把多个科技资讯源（RSS/网页）抓取为**每日一期 EPUB**，用 KOReader 原生阅读器阅读。

## 功能

- **多源订阅**：内置 32 个源（国内 25：IT之家、雷锋网、爱范儿、极客公园、Solidot、少数派、36氪、虎嗅、钛媒体、量子位、InfoQ、掘金、博客园、数字尾巴、快科技、机核、游研社、阮一峰周刊、美团技术、知乎日报、「一个」、Readhub 早报、60秒读懂世界、读首诗再睡觉、触乐；境外 7 个英文源）；可在「设置 → 订阅源设置」按需勾选
- **每日一期**：严格取本地当日 0 点后的条目（不回补），按时间倒序；支持合并期与单源阅读
- **按日期回溯**：分源阅读点开源后可选「今日 / 昨日 / 近一周 / 自定义日期」；日报类源（知乎日报、「一个」、Readhub 早报、60秒读懂世界）可取到真正的往期，RSS 源受限于只提供近期条目
- **全屏首页**：主菜单单入口 → 全屏首页（今日一期 / 抓取往期 / 分源阅读 / 我的收藏 / 往期缓存 / 设置 / 关于）
- **图文完整**：收录文章全部图片，经 CDN 缩放（宽 800）控制体积；跨源标题自动去重；早报/日报/周刊等聚合长文在目录里提供二级跳转（普通文章不建）
- **文章收藏**：阅读时一键收藏/取消，收藏为单篇快照 EPUB（打开即正文，独立于缓存，永久保存）
- **阅读体验**：左上角「⋯」快捷菜单（目录 / 收藏 / 删除并返回 / 关闭并返回）；读到最后一页会问是否返回
- **省心**：缓存保留 7 天自动清理；当日可一键重抓；抓取进度可读、可取消

## 安装

1. 把 `zhifou.koplugin/` 整个目录拷到 KOReader 的 `plugins/` 目录（如 `koreader/plugins/`）
2. 重启 KOReader
3. 主菜单 → 工具 → **知否**

> 需要联网；订阅源可在「设置 → 订阅源设置」中按需勾选（默认启用 IT之家、雷锋网）。

## 使用

- **今日一期**：抓取全部已启用源 → 生成合并期 → 自动打开；已有今日一期时询问「打开 / 重新抓取」
- **抓取往期**：合并期按「昨日 / 近一周 / 自定义日期」抓取（日报类源可真正回溯；抓取过的会进「往期缓存」）
- **我的收藏**：收藏列表（标题 · 收藏日期），点击打开单篇快照；「设置 → 管理收藏」可删除
- **分源阅读**：只列**已订阅**的源；点某个源后选时间范围（今日 / 昨日 / 近一周 / 自定义日期）再抓取
- **往期缓存**：列出本机缓存过的各期刊物（近 7 天），点击直接打开
- **设置**：订阅源设置（勾选启停）、包含图片（默认开）、缓存清理（逐期选择删除，可清全部）
- **阅读器内**：左上角「⋯」打开快捷菜单（目录 / 收藏文章 / 删除并返回 / 关闭并返回）
- 快捷菜单也可绑手势：Dispatcher 动作 `zhifou_quickmenu`

## 开发

```bash
bash scripts/run_specs.sh                # Lua 规格测试（11 个 spec / 388 项断言）
luacheck zhifou.koplugin spec          # 静态检查
bash scripts/make_snapshot.sh "<描述>"   # 里程碑快照（可安装 ZIP + 完整 git 历史 bundle）
```

实现零第三方依赖，全部为纯 Lua：手写最小 EPUB 构建（流式写盘）、最小 ZIP 读取器（收藏就地取图）、RSS 解析与网页正文抽取。

里程碑节奏：提交 → 升 `main.lua` 版本号 → `git tag` → 打快照（`snapshots/`，不进版本库）。
