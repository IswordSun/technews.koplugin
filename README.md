# technews.koplugin

个人自用的 KOReader 插件：把多个科技资讯源（RSS/网页）抓取为**每日一期 EPUB**，用 KOReader 原生阅读器阅读。

## 功能

- **多源订阅**：内置 6 个源（IT之家、雷锋网、爱范儿、极客公园、Solidot、少数派）；首次打开多选订阅，可在「订阅源设置」随时调整
- **每日一期**：严格取本地当日 0 点后的条目（不回补），按时间倒序；支持合并期与单源阅读
- **全屏首页**：主菜单单入口 → app 式全屏界面（打开今日资讯 / 我的收藏 / 分源阅读 / 设置集中）
- **图文完整**：收录文章全部图片，经 CDN 缩放（宽 800）控制体积；跨源标题自动去重
- **文章收藏**：阅读时一键收藏/取消，收藏为单篇快照 EPUB（独立于缓存，永久保存）
- **省心**：每日缓存保留 7 天自动清理；可选「缓存 6 小时后自动更新」；抓取进度可读、可取消

## 安装

1. 把 `technews.koplugin/` 整个目录拷到 KOReader 的 `plugins/` 目录（如 `koreader/plugins/`）
2. 重启 KOReader
3. 主菜单 → 工具 → **科技资讯订阅**

> 需要联网；首次打开会引导选择订阅源。

## 使用

- **打开今日资讯**：抓取全部已启用源 → 生成合并期 → 自动打开
- **阅读器内**：阅读菜单可「收藏 / 取消收藏当前文章」（自动识别当前章节）
- **我的收藏**：首页入口，收藏列表 + 管理删除
- **设置**：订阅源设置（勾选启停）、包含图片、缓存 6 小时后自动更新、重新抓取今日、清理全部缓存
